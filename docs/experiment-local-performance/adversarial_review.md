# 对抗验证：固定本地真实 SQL 工作量

日期：2026-10-17。最终审查者未执行前三轮实验、构建或 benchmark，也未修改产品源码。先独立预审，再读取完成的 [综合结论](conclusion.md)、三轮报告及独立验证、原始输出、源码归档、构建记录和保存的实际二进制；仅执行只读与纯计算核对。

**最终裁定：CONCLUSION_STANDS。** 未找到足以推翻“冻结 candidate03 在预先固定的 local-sql-v1 请求集合通过 1.5× 门槛”的致命或严重缺陷。两对为 **2.370838406× / 2.421294477×**，配对中位数 **2.396066442×**，所有阶段通过预设回退门槛。此裁定不扩展为持续热连接、所有本地读写、生产吞吐或完整兼容性结论。

## 攻击一：总体收益由不具普遍性的重开权重主导

这是最强的外部效度攻击。三个综合 reopen 在最终 A1/A2 总量中占 **59.7601% / 62.2961%**；对相同数据排除这三个阶段后，其余六阶段合计倍数仅 **1.043769× / 1.001178×**。热读和 checkpoint 的配对中位数为 **0.980467× / 0.988709×**，历史提交为 **1.018935×**。所以“所有热读写提高约 2.4×”会被数据直接推翻。

但该攻击没有推翻既定门槛：重开与完整历史增长事先写入 [规划](00_plan.md)，三轮没有改权重或删除阶段；综合结论已明确加入上述敏感性计算，并把主要收益限定在重开。**严重程度：对泛化结论严重；对当前限定结论为已披露的中等局限。** 若将来要求热连接 1.5×，需要另行固定对应负载并测量，当前结果不能代用。

## 攻击二：Cargo stale artifact 或来源标签伪装了候选

仅检查两臂 binary hash 不同，确实无法证明编译来源；本项目此前还实际发生过 mtime=0 导致候选复用 A 的错误产物。审查因此直接读取实物，而非只信环境变量 source 标签。

- candidate02/03 tar 的 **724 / 725** 个 manifest 文件逐项摘要正确；manifest 精确字节 hash 等于 source ID，tar 与保存 binary 的实际 SHA 均与记录一致。
- candidate03 产品 lib 与 integration 构建记录均为 `fresh=false / opt_level=3 / debug_assertions=false`，build-finished success。相对 candidate02 只有 semantic 实现、新测试及外部 `cfg(test)` maintenance 测试三项变化；测试模块不进入 integration benchmark 链接的产品 lib。
- A 早先日志中的产品 lib `fresh=true` 是具体来源缺口。实验结束后的 [强制重编补证](evidence/baseline-rebuild/verification.json) 从固定 `1198b18` 重装源码，lib 与 integration 均 `fresh=false`。审查重新生成 git archive，字节精确等于保存 baseline.tar；直接读取 rebuilt 和正式 A，二者 SHA 同为 `a8fdfb33849581d77d9a39e06bce056b054f618b04f2579d0cbf95b2eb2811f3`。由此补齐正式已测 A 的来源链，未替换性能样本。
- 审查发现补证 manifest 最初遗漏 `rust-toolchain.toml`，已通知主线程补齐并复核。现在 **719** 项恰为 archive 的 718 文件加冻结 harness，全部 archive 成员摘要相同，manifest hash 与新记录相符。repo/lab 的工具链文件也与 archive 逐字节一致。Turso 为固定 `24a3a4609683b73935888f8bc30b47727d100aa8`，工作树干净。

**严重程度：若未解决可致命；目前已补证，不构成剩余缺陷。** 审查者没有自行重建；证据是归档、实际构建记录及重建 binary 与正式 binary 的字节同一性。最新工作区后来修改的 platform/maintenance/runtime 文件不能自动继承冻结结果。

## 攻击三：正向缓存跳过损坏检查、fencing 或 GC 标记

静态复核 `semantic.rs`、`migration.rs`、`branch.rs` 及对应回归，尝试寻找缓存身份混淆与失败状态污染。

Walker 借用固定 `&CatalogRoot`，chunk miss 仍依次验证 hash、logical mapping、entry hash、完整 physical registration 与 tombstone；成功后才缓存。缓存仅属该 Walker，最多 4096 项，淘汰后重新检查。GC 模式首次 `direct` 已加入 reachable，后续命中和 FIFO 淘汰均不移除此集合。浅 `'w'` 与深 `'W'` 标记分离，浅检查不能使深扫跳过 chunk。

boot admission 只在持久组成功并取得 root etag 后记录精确编码 digest；CAS 重试、Unknown 落盘前后不提前授信候选。外来 root 仍经过深校验。accepted WAL image 仅在最终选中本次精确 index 时保留；失败/重试不恢复已扩展的未提交 image。丢 ACK 后采用更晚 HEAD/WAL 的原漏 pin 问题已修复：补 pin 交易同一闭包内选择与保护引用，随后采用闭包捕获的点，避免再次采纳更晚未 pin 的返回 root。

读取 candidate03 实际日志确认 Walker 4、boot 4、recovery 14、p4_authority 35、branch 6，合计 **63 passed / 0 failed**。其中 GC 回归实际运行零窗口 GC 后读取并继续提交。未把前两快照测试累计为本轮重跑数量。

**严重程度：潜在致命攻击未找到具体触发路径。** 未见本轮通过删除 Sync、fencing、恢复或注册检查获取性能的证据。补 pin 交易自身第二次丢 ACK/CAS 交错没有独立专门动态回归，其安全性仍部分依赖代码路径推理；不将有限测试说成全部交错证明。

## 攻击四：删掉慢样本、历史成本或校验成本制造 PASS

独立解析三轮 **12** 份正式 stderr：每份唯一 `LOCAL_PERF` 均精确等于 results 对应对象，三轮均完整结束；重新运行 runner 的纯汇总函数，三个 summary 全部一致。12 份非计时 `workload()` 完全相同，最终四份 stdout 均 1 passed / 0 failed。九阶段正整数 ns 的和逐样本精确等于总量。

实验01的 **1.026755× / 0.885801×**、实验02的 **1.507917× / 1.404408×** 都保留且判失败；没有把第二对不利样本删去。错误 harness smoke 与 stale 候选在正式计时前被排除，记录仍保留。512 次真实历史提交全部计入总量；584 次被测提交、832 次有效更新、完整 payload oracle、两次新进程冷恢复与 epoch/fencing 检查没有缩减。

计时确实排除 fixture、预热、模型/SQL 构造、验证查询与比对、spawn/退出、drop/close；因此它只能称固定请求阶段之和。综合结论已明确这一边界。**严重程度：未发现选择性报告或计时口径偷换。** 排除项不能在对外描述中重新被算作已经测得的全生命周期收益。

## 攻击五：只有两对样本，宿主负载差异也可能解释改善

最终只有 AB/BA 两对，边界 load 不能排除全部资源竞争，也不能提供稳定置信区间、p99 或长期容量保证。开发过程中逐轮调整候选也意味着最终两对不能当作未经探索选择的统计显著性检验。

但正式 A 在两种顺序下都约 24 s，B 都约 10 s，总倍数都远高于门槛；三个综合 reopen 均在两对稳定改善，其他阶段近 1×。针对性的真实 registry page GET 回归也与减少共享前缀重复解析这一机制相符。当前没有数据支持仅由顺序/主机噪声解释全部差异。原门槛为两个实际配对均 ≥1.5，而非统计总体参数保证，最终样本满足它。

**严重程度：中等，降低外推置信度，不推翻本次实际门槛。** 如需长期稳定收益保证，再设计跨时间批次的重复测量；本次无需为已满足的固定门槛追加可选 benchmark。

## 攻击六：正常重开不能证明崩溃耐久性或单项因果收益

graceful close 后冷读可能受额外同步影响，不能替代提交返回后立即崩溃/断电试验；OS/设备缓存也未清空。候选未修改被测路径的持久屏障，且有恢复/Unknown/fencing 针对性证据，但仍不能宣布所有故障场景或完整 SQL/SDK 矩阵全绿。

另外，三轮都是完整候选对原 A。没有同批次 candidate02 对 candidate03 的单项对照，没有内部函数分段计时。故 **2.396×** 只属于组合快照，**16–18×** 只属于综合 reopen，不能全部归因成某一个函数的独立加速。结论已保持这些边界。**严重程度：中等，限制解释与适用范围。** 未发现当前限定结论越过这些证据。
