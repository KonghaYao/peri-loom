方向：worker 的只读 cursor 页不再先构造 `serde_json::Value` 树（每格一次 Value 分配、文本整页
再复制一次），改为把引擎行直接序列化进响应；映射逐条对齐 `sessions::value`：
Null→null、Integer→i64、Float→有限 f64/非有限 null、Text→字符串（同一 serde_json 转义）、
Blob→u8 数组。只读首帧另带 `cols`/`autocommit`，其余命令与写 cursor 保持原 Value 树路径。

上限依据（已测）：
- R53 探针：每页 `json!` 树 36–71µs、`to_vec` 129–206µs（34 页/查询）。

  逐字节等价。
