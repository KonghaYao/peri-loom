P1 design (interleaved, block means)
------------------------------------
Request    one Hrana JSON pipeline request
           {"requests":[{"type":"execute","stmt":{"sql":"SELECT 1",
            "want_rows":true}},{"type":"close"}]}
           over one keep-alive connection per stack.
Block      exactly 20 consecutive requests; the block sample is the wall clock
           of those 20 requests divided by 20 (milliseconds per request).
Triple     three blocks: A1 (stack A), A2 (stack A), B (stack B).
Order      the order of A1, A2 and B inside every triple is a random
           permutation drawn sequentially from random.Random(20261105). A
           void triple retried later draws a fresh permutation from the same
           stream.
Pacing     0.75 s between consecutive blocks (including across triple and
           round boundaries), 1.2 s after seeding before the first block, 5 s
           between round 1 and round 2. Requests inside a block stay
           consecutive; the quota is never relaxed.
Rounds     2 rounds x 30 triples = 60 triples.
Volume      A side: 2 x 20 x 60 = 2400 requests; B side: 1 x 20 x 60 = 1200
           requests.
Continuity The same two stacks, binaries, volumes and configuration run both
           rounds. No restart, rebuild or re-seed between rounds.
Validity   A block with any transport error, non-200 response, or rejected
           pipeline result is failed. A triple with any failed block is VOID:
           it is recorded, excluded from every statistic, and retried after an
           extra pause (3 s, doubling on each consecutive void up to 60 s).
           Failures are reported, never hidden.

P0 — power controls (both must pass before P1 may be interpreted)
-----------------------------------------------------------------
P0.1 zero control (A1 vs A2, same stack, same time window)
  For every valid triple i:  r_i = A2_i / A1_i   (block means).
  merged = median(r_i over the 60 valid triples).
  PASS iff 0.95 <= merged <= 1.05 AND the percentile-bootstrap 95% CI of the
  median covers 1.0.
  Bootstrap: 10,000 draws, seed 20261105, resampling the 60 per-triple ratios
  with replacement (percentile interval).
  Per-round medians and CIs are reported but do not add a pass condition.
  If P0.1 fails, the design has insufficient power and P1 must NOT be
  interpreted.

P0.2 positive control (100 us busy wait, same interleaved design)
  Probe platform binary: SHA256
  6517583e751e2dd936c44fcbd80dd77d13b10757503a0917a7f83bad16096916
  (probe branch probe/r70-deferred-close-ceiling commit f01cd8e; busy wait
  measured at 100.04 us p50 in Gate 1b). Both stacks of this control use the
  probe binary and the probe worktree's dev.py. The B stack additionally has
  PERI_R71_CLOSE_DELAY_US=100; the A stack does not.
  Design: exactly the P1 triple design, 1 round x 30 triples (same block size,
  pacing, randomization seed and validity rule).
  effect_i = B_i / mean(A1_i, A2_i).
  PASS iff the median of the 30 effects is >= 1.08 (B slower in the correct
  direction). The bootstrap 95% CI (10,000 draws, seed 20261105) is reported
  as supporting evidence but is not a pass condition.
  This control is run separately and is never pooled with the candidate
  triples. If the probe binary cannot run under the dual-stack design, the
  campaign reports that fact and does not relax the criterion; the
  coordinator decides whether to fall back to the Gate 1b registered result
  (which is a different design and must be labelled as such).

P1 — primary metric
-------------------
  For every valid triple i:
    a_i = mean(A1_i, A2_i)          (mean of the two block means)
    effect_i = B_i / a_i
  merged ratio = median(effect_i over the 60 valid triples).
  Bootstrap: 10,000 percentile draws, seed 20261105, resampling the 60
  per-triple effects with replacement.
  Per-round ratio = median of that round's 30 effects; per-round bootstrap CIs
  are reported.
  PASS iff ALL of:
    (a) merged ratio <= 0.92  (>= 8% improvement);
    (b) bootstrap 95% CI upper bound < 1.0 (the interval excludes 1.0);
    (c) both round ratios are < 1.0 (same direction in both rounds).
  0.92 < merged ratio < 1.00 => FAIL. No post-hoc threshold changes.
  Also reported (not a pass condition): paired absolute difference
  d_i = B_i - a_i in ms, its median, and the percentile-bootstrap 95% CI of
  that median (10,000 draws, seed 20261105, resampling the 60 pairs).
