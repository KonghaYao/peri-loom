## 正式验收协议

- 每轮顺序 A1 → B1 → B2 → A2；H4/H6 每臂各 2000 次 timed samples，两轮共 32000 次 timed operations。
- 相同 SDK 1.4.1、验证 TLS、默认 pack/completion/writer-admission/observer OFF；每场景独立新卷，512 次 prelude 写读、50 次 warmup、C1 串行、实际 issued 间隔至少 50 ms，不追赶并发。
- 每轮两个 A 臂和两个 B 臂分别汇总后，H4/H6 p99 均至少下降 20%；同时报告每臂与邻近配对，任一重复出现的 p99 回退不算稳定改善。
- 每轮 H4/H6 超过 100 ms 的比例下降；p50 回退不超过 5%。报告 p95、max、样本数、错误、完整时间序列与不确定性。
- 不因结果不利而丢弃或重跑替换。实验中断/无效的原因和已产生记录一并保留。测量时禁止构建、测试或其他主动负载。
- 所有 ACK 的 ID/值/hash 精确校验，close ACK 有证明，0 Unknown/429/SQL replay；clean stop 与恢复校验单独记录。

## 不可突破的边界

维持 durable intent → native commit → terminal → audit → ACK 的语义、存储 fencing、single-writer/WAL isolation、无状态 Worker 与 Go/Rust 分工；不移动 Turso gitlink，不变更生产表结构，不提前 ACK，不自动重试 SQL，不删除 dirty marker 或恢复证明，不关闭 TLS 验证。
