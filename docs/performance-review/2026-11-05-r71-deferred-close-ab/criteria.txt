P1 — primary metric (block mean)
--------------------------------
Sample     total wall clock of 100 consecutive pipeline requests
           {"requests":[{"type":"execute","stmt":{"sql":"SELECT 1",
            "want_rows":true}},{"type":"close"}]} divided by 100.
Leg        1 warm-up block + 30 timed blocks, first block after 1.2 s,
           block gap 0.75 s (default quota refill; requests inside a block stay
           consecutive and the quota is not relaxed), one keep-alive connection.
Design     2 rounds x A/B/B/A = 8 legs:
           r1-a1 r1-b1 r1-b2 r1-a2 r2-a1 r2-b1 r2-b2 r2-a2
Merged     median of all pooled timed blocks on B / median of all pooled timed
           blocks on A.
Round      same ratio computed per round from that round's two A legs and two B
           legs.
Bootstrap  percentile bootstrap, 10,000 draws, fixed 20261105 seed.
           (a) ratio CI: resample blocks within each side;
           (b) paired CI: within each round pair a1<->b1 and a2<->b2 by block
               index; 120 pairs total; resample pairs; the 95% CI of the median
               per-request difference (B - A, milliseconds) must exclude 0
               (i.e. its upper bound must be < 0 for an improvement).
PASS       both rounds same direction (B/A < 1 in both rounds)
           AND merged median ratio <= 0.92 (>= 8% improvement; this round's
           pre-registered exception, because Gate 1b A/A showed ~9%
           position/round drift)
           AND paired bootstrap 95% CI excludes 0.
           0.92 < merged ratio < 1.00 (less than 8%) => FAIL.
           No post-hoc threshold changes.
