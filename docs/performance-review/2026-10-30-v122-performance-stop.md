## 已验证结果

最新正式对照为 JSON 专用行编码 `1059775` 对基线 `e5096d2`，共同使用 native `b6746f3`，
同轮对照 sqld；A/S/B/B/S/A 交错，840 个计时业务、180 个预热业务。

| 场景 | 基线平均 → 候选平均 | 平均延迟下降 | 提速 A/B | 候选平均 / sqld | 候选 p99 / sqld p99 |
|---|---:|---:|---:|---:|---:|
| 单行 | 12.654 → 11.641 ms | 8.01% | 1.087× | 2.447× | 20.725 / 11.759 ms = 1.762× |
| 大文本 | 390.137 → 364.357 ms | 6.61% | 1.071× | 2.284× | 439.039 / 197.048 ms = 2.228× |
| 大结果全列 | 390.630 → 367.300 ms | 5.97% | 1.064× | 2.302× | 454.702 / 194.223 ms = 2.341× |

这些是同一轮合并统计，不能与其他轮次拼成累计提速。单行第二组平均回退 5.53%，大文本第二组
p95 回退 6.00%，全列第一组 p50 回退 0.75%；因此不构成所有指标稳定改善，也不支持全面替换。
`76433aa` 的首批结果复用只有功能验证，尚无性能对照。
