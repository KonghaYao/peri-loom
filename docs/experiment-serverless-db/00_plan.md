# Serverless DB 压力与生命周期性能实验计划

## 目标

给出本仓库在当前机器、当前部署方式下的可复现性能数据：SQL 热路径压力梯度和 serverless 生命周期指标。报告严格区分实测、合同目标与未测。

## 方法

1. 固定代码版本、主机、部署拓扑和负载工具，检查 `/readyz` 与真实 SQL 请求。
2. 热库预热后逐级增加并发，记录完成请求数、RPS、成功率、p50/p95/p99 和资源占用；出现显著错误或吞吐平台期时停止扩压。
3. 使用独立数据库样本测量冷启动、同库并发唤醒以及可行的回收/恢复场景。
4. 保存原始命令和输出。第一次采样后检查请求确实进入数据库，再复测关键点。
5. 将复核意见和局限性纳入结论，不以设计目标代替测量值。

## 变量

自变量：并发数、热/冷状态、读/写请求类型（若可用）。因变量：吞吐、延迟分位数、错误率、唤醒时间、资源使用。控制变量：二进制、主机、数据库、SQL、部署拓扑和每档持续时间。

## 执行边界

同一时间仅一个执行者启动服务并施加负载，避免本机资源竞争污染测量。测试数据使用隔离目录，结束后清理测试服务。若分布式拓扑不可用，报告按实际可运行模式标注，不能外推为分布式性能。
