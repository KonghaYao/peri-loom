# Simple 单机空闲队列等待修复后复测

## 条件与数据

仅改变 `crates/database-host/src/lib.rs` 的无活动事务空闲等待：原来 `try_recv` 失败后睡眠 10 ms；本轮使用 `commands.blocking_recv()` 等待新命令。有活动事务时仍保留原来的定期唤醒逻辑。使用同一 [诊断脚本](bench_perf_diagnosis.py)、相同的两轮顺序、每类每轮 120 次、100 次点查预热、单个持久 HTTP 连接和单请求串行发压。每次启动使用独立的随机端口及临时数据目录；旧基线数据未覆盖。本轮 release 二进制 SHA-256 为 `5c8ec697ff7ee666f17ae06487612357c2c93e46c607a201ef9c12c130e6bbe7`，旧版为 `8e3c2473e7ac05292b9925278fd852a213b228f88e203d49246cc602ab2b3184`。最终代码增加 `sessions.is_empty()` 限制以保留闲置会话定时清理，最终二进制的额外复测见[总结](perf_diagnosis_conclusion.md)。

新原始数据：[samples.csv](raw/perf_diagnosis_after/samples.csv)（960 条，无凭据）、[metadata.json](raw/perf_diagnosis_after/metadata.json)、[server.log](raw/perf_diagnosis_after/server.log)；旧原始数据：[samples.csv](raw/perf_diagnosis/samples.csv)。计时口径详见[基线报告](perf_diagnosis_experiment.md)。以下值均为毫秒，P 分位对升序样本取零基下标 `ceil((N-1)×p)` 的值；`elapsed_micros` 是响应中的服务执行计时，从 `host.execute(...).await` 后开始，不等于纯 SQL 引擎耗时。

复现命令：

```sh
python3 docs/experiment-serverless-db/bench_perf_diagnosis.py \
  --binary target/release/peri-loom \
  --output docs/experiment-serverless-db/raw/perf_diagnosis_after
```

## 响应 `elapsed_micros` 对照：P50 / P95 / P99

| 请求 | 轮次 | 修复前 | 修复后 | 修复后计时器外 P50 / P95 / P99 |
|---|---:|---:|---:|---:|
| 主键点查 | 1 | 12.171 / 15.564 / 16.772 | **0.040 / 0.105 / 2.990** | 0.291 / 0.352 / 0.452 |
| 主键点查 | 2 | 11.914 / 15.699 / 16.262 | **0.043 / 0.098 / 5.613** | 0.283 / 0.374 / 0.454 |
| 单行同步写入 | 1 | 15.069 / 19.275 / 21.031 | **3.554 / 9.534 / 12.208** | 0.498 / 0.669 / 0.843 |
| 单行同步写入 | 2 | 14.998 / 18.538 / 19.314 | **3.578 / 6.600 / 7.469** | 0.482 / 0.839 / 1.071 |

客户端和服务端都显著改善，而非 SQL 路由维持同一数量级，支持原 10 ms 轮询是先前单并发延迟的主要原因。两轮读 P50 均提高约 **39 倍**；写 P50 提高约 **4 倍**。写请求 `elapsed_micros` 的 P50 仍为 3.55–3.58 ms，约占客户端 P50 的 88%，下一步要把引擎写入、WAL 同步和无条件目录同步分别计时才能定位剩余成本。只读请求仍执行 `sync_dir`，但当前 40–43 µs 的服务计时 P50 说明热读中位数没有明显毫秒级同步代价；偶发读 P99 为 3–6 ms，不能在没有内部埋点和更多样本时归因。

验证：两轮各 120 次读返回 `[[42]]`；两轮共 240 次写均返回 `affected_rows=1`，末尾行数 241（含初始 1 行）。此为本机 macOS ARM64 短时、单行数据、单并发实验；高并发排队、长时间吞吐、远程客户端和原版 TursoDB 尚未在此对照中测量。尤其不能据此断言先前 32/64 并发 P95/P99 已同幅度改善，仍需另做并发实验。
