## 假设与反证

| ID | 待挑战判断 | 最强反证/替代解释 |
| --- | --- | --- |
| H1 | operation 1 MiB 缓冲造成高分配 | 编译器消除分配；合批或 fsync 主导使其端到端收益很小 |
| H2 | Authority 响应双解析有明显成本 | 响应很小，网络与校验主导；单解析改变缺失/null/重复字段契约 |
| H3 | 内层锁外读仍被外层 Shared 锁串行化 | 外层 guard 可能提早释放；真实 File 入口或并发路径不共享该锁 |
| H4 | WAL 复制/索引处理随历史增长 | clone 共享底层字节；compact/页重用使实际工作不增长；并非每次提交进入增量路径 |
| H5 | checkpoint 有稀疏上传放大与串行成本 | 内容去重、批次接口或实际调用条件使 payload/请求数远小于推算 |
| H6 | ownership root 解码与 commands 成本增长 | 新合入 memo 已消除重复解析；仅规模成本成立但不是当前主瓶颈 |
| H7 | 两道日志屏障是当前热读主因 | 59% 来自旧构建共享机，不能代表当前版本或后端；现有合批改变占比 |
