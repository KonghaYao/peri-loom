# v1.0.1 四项生产能力模拟验收结论

## 范围与总判定

被测对象为发布镜像 `ghcr.io/konghayao/peri-loom@sha256:901f37f2cceb62bf265072e5b0159fa86974af3440a79383ba31e351c0895333`。所有运行资源使用随机 owner 标签和独立状态；S3 测试使用独立 RustFS 与桶。环境是本地 Docker Linux daemon 上的 `linux/amd64` 应用镜像，宿主为 `arm64`。本报告评判**这些模拟条件下的四项验收门槛**，不将单宿主结果推广为所有外部编排或生产故障域。

**总判定：四项均已执行实际检测；v1.0.1 未通过生产能力验收。** 正常停机后恢复成立。异常终止后的业务恢复失败。预先备份的手动恢复在模拟环境中成立，但生产灾备流程尚不具备已验证的备份策略、跨故障域恢复和旧副本 fencing。S3 同卷备用虽由故障前启动的测试 watcher 自动尝试接管，仍被 dirty guard 拒绝，固定客户端入口 60 秒内不可用。完整状态卷的两个独立克隆在 `local` 后端出现同身份双活动与数据分叉；共享 S3 桶的相同诊断则在第二克隆启动时被后端 dirty seal 拒绝。

| 能力与通过条件 | 实测判定 | 核心证据与边界 |
| --- | --- | --- |
| **1. 干净停机后恢复**：同库同凭据且确认写入可读 | **通过** | S3 隔离桶上 `TERM` 退出 0，Authority `clean`；同卷再启有新 ready、同库同 key，首笔写入经 TLS SQL 读回。第 3 轮独立复核为 PASS。 |
| **2. 异常中断后恢复**：KILL 后不绕过 guard 即恢复同身份 SQL | **失败；安全拒绝通过** | S3 测试 KILL 退出 137、标记 `dirty`；原卷再启进程退出 1，无新 ready，不能做故障后 SQL 读回。本地后端独立实验同样失败。持久字节是否完整未证实。 |
| **3. 灾难恢复**：故障前独立备份，新卷与对象存储恢复，量化 RPO/RTO | **模拟手动恢复通过；生产验收部分完成** | 整个应用卷与 13 个 S3 对象在 clean 停机后冷备份。最终重跑在故障后按 owner 标签移除模拟源容器和源卷，仅用私有归档恢复到新卷；同库同凭据、A 可读，备份后的确认写入 B 丢失。原始单调时间可复算模拟 RPO **4.028 秒**、RTO **3.363 秒**。缺周期备份、异机恢复和旧副本隔离。 |
| **4. 高可用与自动接管**：同一客户端入口自动恢复读写 | **被测 S3 同卷接管失败** | 第 8 轮预创建备用和故障前启动的外部测试 watcher；主实例 KILL 后约 0.41 秒自动执行 `docker start`，备用仍退出 1、无 ready；固定 TLS URL 约 60 秒内 56 次探测均失败。第 5 轮无 watcher 的本地单实例对照也失败。watcher 属于测试辅助，不是产品内置 HA；未测试不同故障域的外部 HA 控制器。 |

## 额外安全发现：完整卷克隆双活动

第 6 轮从一个 clean 状态归档恢复到两个独立本地卷；两个克隆同时就绪，数据库标识和项目凭据相同，在 1.933 秒重叠检查期间分别确认写入，并各自读不到对方的新表。独立核验确认了源归档、双卷、双进程及 SQL 时间线。**同卷锁不能约束跨卷克隆。** 第 9 轮在共享 S3 桶上重复跨卷冷克隆，克隆 A 就绪并读回源写入，克隆 B 因后端 dirty Authority seal 退出、没有 ready；该时序未出现双活动写入。两种后端的结果不同，不能把本地分叉外推成共享 S3 的必然行为，也不能凭单次 S3 拒绝认定所有故障时序都安全。第 2、4 轮的冷克隆/冷备份读回仍只是功能证据；正式主备流程需要验证旧副本隔离、全局 fencing 和身份接管。

## 尚未通过的生产门槛

1. **异常恢复**：需要在不删除或伪造 `dirty`/stop proof 的前提下，判定未决操作与写入结果，并恢复同一身份的业务服务。
2. **灾备**：需要有定期、可校验、同时覆盖私有状态和 S3 对象的独立备份；在跨故障域条件下测恢复，并定义可接受的 RPO/RTO。当前数字只适用于同宿主小数据量手动流程。
3. **HA 和克隆安全**：需要全局独占租约/fencing、旧副本隔离和跨故障域自动接管；用同一客户端入口持续读写，记录失败窗口并验证无双主和确认写入一致性。第 8 轮在同卷备用上连就绪都未达到，后续成功读写门槛无法执行；这已足以判定该接管路径失败。

详细成功标准与隔离约束见[实验计划](./00_plan.md)。私有证据目录包含凭据和原值，不应复制到公开仓库。模拟资源均由随机标签识别，成功实验的活动应用在复核后已正常停止；保留的失败容器、卷与私有证据供后续审计。
