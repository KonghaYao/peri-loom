## 判定

**完整状态卷的本地冷克隆缺少跨卷独占保护；本轮观察到同身份双活动与写入分叉。** 同卷 `flock` 可阻止两个进程共享一卷启动，但不约束由同一干净状态复制出的两个不同卷。若把这类克隆当成服务主备，必须先有可审计的旧副本隔离、身份撤销或外部租约/fencing；当前冷克隆读回实验不能算安全迁移验收。

本轮两个写入是先后发出的，只要求在两进程持续运行的重叠区间内分别成功；没有模拟同一毫秒并发的写请求。`local` 后端的分叉不直接证明共享 S3 桶时的写入结果，也没有测试跨主机网络分区。它足以反驳“复制完整卷后会自动保持全局单主”的假设。

独立复核采集运行状态后，对本轮 A、B 两个带标签容器发送 `TERM`，两者均正常退出码 0；卷、容器和私有证据仍保留。双活动结论依据故障注入时记录的重叠时间线及复核时的在线观察，不依赖它们持续占用资源。
