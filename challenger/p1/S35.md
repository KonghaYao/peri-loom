# S35｜单库损坏/不可用的故障域（Tailscale 启发，需夹具注入）

> 优先级：P1 · 第 16 位；待验证，不代表已通过。执行和判定须遵循[共用验证合同](../ORDERED_SCENARIOS.md)。

## 场景与判定

在自己拥有的单个 namespace 中注入**安全、可回滚的受控不可用**，并保持其他租户独立读写；观察 Gateway/Controller 是否把故障传播成跨库不可用、泄漏错误详情或错误迁移，按每 project ACK 与出错窗口验算。绝不直接破坏共享桶或生产数据。

研究依据：[Turso、Tailscale、Neon 架构研究](../ARCHITECTURE_RESEARCH.md)；仅借鉴风险，不代表本项目存在相同缺陷。
