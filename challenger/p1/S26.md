# S26｜在线 schema 变更与旧会话（需专用迁移夹具）

> 优先级：P1 · 第 21 位；待验证，不代表已通过。执行和判定须遵循[共用验证合同](../ORDERED_SCENARIOS.md)。

## 场景与判定

大量读写/预备语句未结束时进行 ADD COLUMN、重命名表/列、建索引及旧会话重新准备；逐步核验旧语句的错误分类、触发器/view/外键引用、最终 schema 和数据 hash，不得直接把未支持 DDL 当成功执行。与已知 view rename 风险隔离报告。来源：[SQLite ALTER TABLE 行为](https://www.sqlite.org/lang_altertable.html)。
